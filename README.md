#Copaste Tool

Crie um novo favorito no navegador e cole o código abaixo na URL do favorito:

```javascript
javascript:(async()=>{try{const r=await fetch("https://cdn.jsdelivr.net/gh/caiouqz/copaste-tool@main/dist/caioopj.js?"+Date.now());if(!r.ok)throw new Error("HTTP "+r.status);eval(await r.text());}catch(e){console.error(e);alert("Erro ao carregar o Copaste Tool:\n"+e.message);}})();
```
